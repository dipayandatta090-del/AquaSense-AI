# AquaSense AI — Professional Water Quality Prediction

A six-page Streamlit SaaS-style dashboard with prediction, interactive charts, model evaluation, dataset exploration, project information, and downloadable PDF prediction reports.

## Dataset
Add your real labelled CSV as `data/water_potability.csv`. By default the target column must be `Potability` (0/1). The common Kaggle dataset uses numeric features `ph`, `Hardness`, `Solids`, `Chloramines`, `Sulfate`, `Conductivity`, `Organic_carbon`, `Trihalomethanes`, and `Turbidity`. If your target column differs, edit `TARGET` in `config.py`. All numeric columns other than the target are used as model inputs.

## Run locally (Windows / VS Code)
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python train.py
streamlit run app.py
```
On macOS/Linux activate with `source .venv/bin/activate`.

## Online deployment (Streamlit Community Cloud)
1. Create a GitHub repository and upload the project.
2. Ensure `requirements.txt` is at the repository root.
3. Add trained model artifacts (`output/models/aquasense_model.joblib` and `output/models/metadata.json`) and `output/metrics.json` if you want the deployed app to show predictions and evaluation. These files are generated by `python train.py`.
4. Do not commit private data, secrets, or a dataset unless its licence permits public redistribution.
5. Visit https://share.streamlit.io/, connect GitHub, select the repository/branch, set `app.py` as the main file, and deploy.

Cloud deployment runs on a separate machine: files on your laptop are not automatically uploaded. Include permitted model artifacts in the repository or use an appropriate private storage solution. The model and metadata must be present in the cloud app environment.

## PDF report
After a prediction, click **Download prediction report (PDF)**. The report includes timestamp, entered values, predicted class, class probabilities and a safety disclaimer.

## Notes
The model uses median imputation and a Random Forest classifier with an 80/20 train/test split. Metrics are generated from the held-out test set. A model estimate is not a laboratory certificate and must not be used alone to determine drinking-water safety.
